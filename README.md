# Сити-Центр · Новая география

Отдельный сайт-презентация проекта пяти офисов в России, 2027.

Источник: Google Sheets «Сити-Центр — 5 офисов в России, 2027». Основной план — лист «Базовая стретегия», прочитан 29.10.2026. Плановые показатели отделены от подтверждённых результатов и сравнительных денежных моделей.

Статический сайт для GitHub Pages. Прежние сайты компании находятся в другом репозитории и не изменяются.

## Запуск

Сайт не требует сборки и внешних сервисов. Для локального просмотра: `python -m http.server 8080`, затем открыть `http://localhost:8080`.

GitHub Pages: ветка `main`, папка `/ (root)`. Все CSS, JavaScript и фотографии расположены в этом репозитории.

## Возможности

- Восемь сцен, пять городов и фотопанорамы с указанием авторства.
- Переключение городов, средних чеков и этапов подготовки.
- Помесячный план: 3 → 18 агентов на офис, 15 → 90 на сеть. Эти числа — планы 2027 года.
- Режим презентации: полноэкранный показ при поддержке браузером; стрелки, Page Up/Down, Home/End, Escape. Слайдеры и городские вкладки сохраняют собственное управление с клавиатуры.
- Уважение настройки уменьшения движения; доступность содержимого без анимаций.
- Основная стратегия и отдельная финансовая модель 2.0 явно различаются. Финансовая версия рассчитана на 12 стартовых и 30 целевых агентов на офис.
- Сайт показывает сохранённый срез; автоматической синхронизации с Google Sheets нет.
